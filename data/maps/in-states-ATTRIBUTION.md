# India ADM1 map attribution

The boundaries in `in-states.svg` are derived from the geoBoundaries India ADM1 dataset:

- Boundary ID: `IND-ADM1-1811400`
- Source: DataMeet India community and Election Commission of India
- Source data update: 19 January 2023
- geoBoundaries build: 12 December 2023
- License: [Creative Commons Attribution 2.5 India](https://creativecommons.org/licenses/by/2.5/in/)
- Dataset: [geoBoundaries India ADM1](https://www.geoboundaries.org/api/current/gbOpen/IND/ADM1/)

The generated SVG uses a simplified GeoJSON file pinned to geoBoundaries commit `9469f09`.
Run `npm run regen:india-map` to regenerate it.

# United States ADM1 map attribution

The boundaries in `us-states.svg` are derived from the geoBoundaries United States ADM1 dataset:

- Boundary ID: `USA-ADM1-66186276`
- Boundary year represented: 2018
- Source: United States Census Bureau, MAF/TIGER Database
- Source data update: 19 January 2023
- geoBoundaries build: 12 December 2023
- License: Public domain
- Dataset: [geoBoundaries United States ADM1](https://www.geoboundaries.org/api/current/gbOpen/USA/ADM1/)

The generated SVG uses a simplified GeoJSON file pinned to geoBoundaries commit `9469f09`.
It includes the 50 states and District of Columbia; U.S. territories are excluded from this state-level view.
Run `npm run regen:us-map` to regenerate it.
